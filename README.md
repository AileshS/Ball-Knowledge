# Ball-Knowledge
An app that will teach you ball knowledge

## Getting started

Requires [Node.js](https://nodejs.org/) 22.12 or newer.

```sh
npm ci           # install dependencies from the lockfile
npm run check    # format check, lint, typecheck, and tests (what CI runs)
```
